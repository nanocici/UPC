# UPC 2026 Problem B 建模报告（最终版）

> 2026-11-08 更新。按 `2analysis-modeling` 的结构重写为最终 F1 + 空间校准 + 时间模型 + 0.10 m 平滑峰版本；历史过程见 `reports/FINAL_CODE_CHANGES.md` 及各阶段报告。

## 1. 题目与子问题

本赛题共 **1 个子问题**（题面没有编号子问题，按一个连续预测任务处理）。内部拆成四个模块：物理正向、两帧反演、条件不确定性、独立验证。

| 项目 | 内容 |
|---|---|
| 输入 | 球心起点 \(r_0=(0,0,0.11)\) m；两帧 \(t_1=0.05,\ t_2=0.10\) s；位置 \((1.50,0.45,0.44)\)、\((2.96,0.86,0.74)\) m；门线 \(x=11\) m，开口 \(-3.66<y<3.66,\ 0<z<2.44\) m |
| 输出 | 首次正向门线交点 \((Y,Z)\)、到达时间 \(T_G\)、空间区域、时间区间、入框概率、事件状态 |
| 目标 | 在明确假设下预测最可能位置，并给出可解释的不确定性；用独立数据检验覆盖与误差 |
| 约束 | 球心门线开口；首个正向过线/下降接地事件；\(v_{0x}>0\)；\(b\) 在圆盘内；固定 \(C_D\) |
| 依赖 | 两帧 → MAP/后验 → 门线事件 → 区域/时间 → 独立测试 |

## 2. 假设敏感性预检

### 2.1 模糊表述及解释

| 歧义 | 解释 A | 解释 B | 采用 |
|---|---|---|---|
| “进入球门” | 球心进入矩形 | 整球按真实半径过线 | 主结果用球心矩形；半径修正作为限制，不混入主区域 |
| 坐标只有两位小数 | 精确值 | 厘米舍入/测量误差 | 主结果用 \(\sigma=0.01\) m 高斯工作假设；舍入另作诊断 |
| “最可能位置” | 二维分布的众数 | 条件均值/评分点 | 主点为 0.10 m 固定带宽平滑峰；均值只作辅助 |
| 空气力 | 固定 \(C_D\) 的等效横向力 | 变阻力/三维自旋/风 | 主模型固定 \(C_D=0.22\)；其余作为 H 压力机制 |
| 守门员 | 无人干预 | 实际扑救 | 只预测无拦截球路，不推出扑救率 |

### 2.2 快速验算与递进性检查

- 两段平均速度约 \((30,9,6.6)\)、\((29.2,8.2,6.0)\) m/s；
- 三点二阶差分约 \((-16,-16,-12)\) m/s²；
- 水平非共线指标 \(D=x_1y_2-y_1x_2\approx-0.042\ \mathrm{m^2}\)；
- 在独立高斯 \(\sigma=0.01\) m 下，二阶差分加速度标准差约 \(8.94\ \mathrm{m/s^2}\)，所以不能仅凭 \(-12\) 断言强侧旋；
- 这些量只用于诊断/初始化，不作为整段飞行假设。

### 2.3 最终采用的解释

- 主模型 F1：固定 \(C_D=0.22\)，静风，\(\sigma=0.01\) m，\(b_y\) 先验 0.10、\(b_z\) 0.20；
- 空间：模型内 90% 椭圆；另给出校准阈值 3.0835 的区域；
- 时间：原后验区间 + 全局 additive 模型误差 \(q=15.1889\) ms；
- 众数：0.10 m 固定带宽平滑峰；原始格网与均值分开报告；
- 不加入自由 \(C_D\)、未知风或三维自旋作为两帧未知量。

### 2.4 绘制的图像和对比表格

- 门线二维候选散点/区域/门框；
- 时间误差按 mechanism × \(\sigma\) 分层；
- F0/F1 覆盖—面积—点误差表；
- 平滑峰带宽敏感性、原始格网 64k 结果；
- 独立 test 覆盖/面积/时间宽度表。

## 3. 数据理解

- 题面只给起点与两帧，没有附件、误差分布、风、自旋或门线真值；
- 由两帧可派生两段速度、平均加速度、水平非共线量；
- 坐标两位小数，厘米舍入是可能的，但主结果采用独立的 \(\sigma=0.01\) m 工作误差；
- 无实测数据；验证全部使用 H 合成机制（常系数、变阻力、自旋、风、组合）。

## 4. 符号与最终模型

| 符号 | 含义 | 设置 |
|---|---|---|
| \(r=(x,y,z)\) | 球心位置 | m，\(x\) 指向球门，\(z\) 向上 |
| \(v\) | 球速 | m/s |
| \(w\) | 风速 | 名义零 |
| \(u=v-w\) | 相对气流 | m/s |
| \(m,R,A\) | 质量、半径、截面积 | 0.43 kg、0.11 m、\(\pi R^2\) |
| \(\rho,g\) | 空气密度、重力 | 1.20 kg/m³、9.81 m/s² |
| \(C_D\) | 阻力系数 | 固定 0.22 |
| \(b=(0,b_y,b_z)\) | 有效横向力系数 | 圆盘内，\(b_y\) 先验 0.10、\(b_z\) 0.20 |
| \(\sigma\) | 每轴观测误差 | 0.01 m |

控制方程：

\[
\dot r=v,\qquad
\dot v=-g e_z+k\|u\|\left[-C_Du+b\times u\right],
\qquad k=\frac{\rho A}{2m}.
\]

门线事件：\(x-L=0\) 的第一个正向穿越；接地事件：\(z-R=0\) 的第一个下降穿越。先到门线才输出 \((Y,Z,T_G)\)，先接地则标为 ground，不拿接地点冒充门线点。

模型角色：

- **F**：主模型，含 \(b_y,b_z\)；
- **S**：F 的限制版 \(b_y=0\)，只作结构对照；
- **G/A**：重力/恒加速度基线；
- **H**：合成数据生成器，不是预测模型。

## 5. 推断与不确定性

### 5.1 两帧反演

观测向量

\[
e(\xi)=\left[p(t_1)-p_1,\ p(t_2)-p_2\right],
\]

高斯工作似然与 MAP：

\[
J(\xi)=\tfrac12 e^\mathsf T\Sigma^{-1}e+\frac{b_y^2}{2s_y^2}+\frac{b_z^2}{2s_z^2},
\]

其中 \(\Sigma=\sigma^2I_6\)，\(s_y=0.10,\ s_z=0.20\)。用 SLSQP 多起点、缩放参数和 KKT 认证；固定 \(C_D\)，F 拟合 5 个参数（F1 先验）。

### 5.2 条件后验

- 在 MAP 附近用完整后验曲率构造 Student-t 混合提议；
- 固定 4000 次提议；用真实似然/先验除以完整提议密度修正权重；
- 输出条件均值、加权 90% 椭圆、入框概率、时间区间；
- 认证采样/ESS/事件质量；不把失败静默删除。

### 5.3 空间区域

模型内 90% 椭圆：

\[
(g-\mu)^\mathsf T V^{-1}(g-\mu)\le q,\qquad
\text{area}=\pi q\sqrt{\det V}.
\]

独立校准后使用阈值 \(q_{\rm cal}=3.0835\)；最终算例同时报告：

- 模型内区域：1.1668 m²；
- 校准区域：0.7659 m²（独立 test 覆盖 88.64%，combined 82.81%）。

### 5.4 时间模型

原后验 90% 时间区间半宽为 \(h\)，最终：

\[
T\in\left[\hat T\pm\sqrt{h^2+q^2}\right],\qquad
q=15.1889\ \mathrm{ms}.
\]

独立 test 覆盖 96.10%，宽度中位 33.68 ms；偏保守，不能靠缩小区间硬凑 90%。

### 5.5 众数/点

- 主点：F1 inside-conditioned、0.10 m 固定带宽 KDE 平滑峰 (2.875,1.925) m；
- 四种子等权，跨种子 0.0224 m，32k→64k 0.0141 m；
- 原始格网 64k：(2.8975,1.8808) m，通过但 0.1833 m 接近 0.20 m；
- 历史 4k/8k/16k 失败保留；
- 均值 (2.9058,1.9285) m 仅辅助，不称最可能点。

## 6. 模型选择与验证结果

### 6.1 F0/F1

第二轮 development：100 源、400 观测、800 任务。

| 指标 | F0 | F1 |
|---|---:|---:|
| 区域面积中位 | 2.083 m² | **1.352 m²** |
| 覆盖 | 95.98% | 94.54% |
| 点误差中位 | 0.334 m | **0.295 m** |
| P90 | 0.644 m | **0.628 m** |
| misfit | 64/348 | 74/348 |

F1 五项空间条件通过；代价是 misfit 增加、时间区间更窄。

### 6.2 时间

- time_model_200：100 calibration/100 test，global additive 覆盖 94.87%，宽 33.66 ms；
- independent_200：test 覆盖 96.10%，宽 33.68 ms；
- 时间点误差仍约 5.5 ms，未因区间校准而变准。

### 6.3 空间校准/独立测试

independent_200：100 calibration/100 test。

| 区域 | test 覆盖 | test 面积中位 |
|---|---:|---:|
| 原模型内 | 95.78% | 1.475 m² |
| 校准 | 88.64% | 0.983 m² |

combined 机制 82.81%，是明确弱点。

### 6.4 阻力

- 真实 Cd oracle：时间 MAE 5.34→2.43 ms；
- 剖面最优 Cd=0.37375：MAE 14.09 ms，过校正；
- 外部/宽 Cd 先验未能复现 oracle；
- 结论：两帧无法可靠识别 Cd；固定 Cd + 时间误差模型是当前可部署版本，不加自由 Cd。

## 8. 灵敏度、误差与局限

| 来源 | 处理/结果 |
|---|---|
| 观测误差 | 主结果 \(\sigma=0.01\) m；更小/更大误差会改变区域宽度，未做最终外部校准 |
| 先验 | F1 收紧 \(b_y\) 降低面积/点误差，但增加 misfit；先验变化会移动点约 0.1–0.3 m |
| 阻力 | Cd 不可识别；固定值偏低/偏高会改变 Z/T；已用时间模型吸收部分误差 |
| 众数 | 0.10 m 平滑峰通过；原始格网 64k 通过但接近阈值；带宽敏感性约 1 cm |
| 模型形式 | LS misfit 约 11.6%，variable_drag/wind 仍是弱点 |
| 真实数据 | 无；结论限于 H 合成机制 |
| 在线 | 完整后验约 7 s；未做快速版 |

## 10. 结论边界

可以支持的表述：

> 在 F1、固定 \(C_D=0.22\)、\(\sigma=0.01\) m、静风、合成机制条件下，指定算例的 0.10 m 平滑峰为 (2.875,1.925) m；模型内 90% 区域 1.1668 m²，校准区域 0.7659 m²；时间区间 [0.371435,0.403940] s。独立 test 空间校准覆盖 88.64%、时间 96.10%。

不能支持的表述：

- “空间 90% 已完全校准”——test 88.64%，combined 82.81%；
- “时间预测已变准”——时间点误差仍约 5.5 ms，区间只是覆盖修正；
- “众数是唯一连续峰”——0.10 m 平滑峰依赖带宽，原始格网仅接近阈值；
- “适用于真实足球”——没有真实数据；
- “等效于门将扑救率”——不建模门将。
