# 固定 \(C_D\) 消融与时间误差模型

日期：2026-11-07（Asia/Shanghai）。
范围：复用 `results/round2_selection` 的 F1 封存预测；对 348 个直接过线案例中的 334 个可拟合案例，分别把 \(C_D\) 固定在“有效真实值”和剖面最优 0.37375 重做 MAP 拟合；另用按机制分层的源级 50/50 划分，在 calibration 半上拟合时间误差项，在 test 半上评估。没有新增后验采样。

## 1. 结论摘要

1. **阻力是时间误差的主要成分之一。** 在共同 334 个案例上，把 \(C_D\) 固定到每个源的有效真实值后，时间 MAE 从 **5.34 ms 降到 2.43 ms**，P90 从 **15.09 ms 降到 8.73 ms**，中位偏差从 -0.46 ms 变为 -0.36 ms。
2. **但“剖面最优 0.37375”不是可用的全局修正。** 同一批案例上，固定 0.37375 使 MAE 升到 **14.09 ms**、P90 升到 **21.63 ms**，明显过校正。真实 \(C_D\) 中位约 0.23–0.29，剖面最优只代表题目算例，不代表总体。
3. **时间误差模型确实需要一项不随 \(\sigma\) 缩小的下限。** 只加全局/分机制误差项后，test 覆盖从 51.1% 升到 82.8%–83.3%，但仍未到 90%；constant/spin 仍明显欠覆盖。
4. **机制条件化没有带来超过全局的收益。** 在当前 50 个 calibration 源下，分机制分位数噪声太大；global additive 与 mechanism additive 都约 83%，宽度约 25 ms。
5. **所以不能只做“固定一个 \(C_D\)”或“只加一个时间 floor”。** 阻力需要按案例/分布处理；时间需要更大的校准集和更保守的区间。

## 2. 固定 \(C_D\) 消融

### 2.1 总体

| 方案 | n | 中位偏差 / ms | MAE / ms | P90 / ms | RMSE / ms |
|---|---:|---:|---:|---:|---:|
| 基线 \(C_D=0.22\) | 348 | -0.37 | 5.29 | 14.88 | 8.64 |
| 有效真实 \(C_D\) | 334 | -0.36 | **2.43** | **8.73** | **5.53** |
| 剖面最优 0.37375 | 334 | +14.09 | 14.09 | 21.63 | 15.27 |

共同 334 案例比较（避免缺失选择偏差）：

| 方案 | MAE / ms | P90 / ms | 中位偏差 / ms |
|---|---:|---:|---:|
| 基线 | 5.34 | 15.09 | -0.46 |
| 有效真实 \(C_D\) | **2.43** | **8.73** | -0.36 |
| 剖面最优 | 14.09 | 21.63 | +14.09 |

真实 Cd 的拟合缺失 14 例（combined 9、spin 5），这些案例在真实 Cd 下未得到直接门线事件；因此真实 Cd 的改善是在较容易子集上评估的，可能略偏乐观。

### 2.2 分机制

| 机制 | 基线 MAE | 真实 Cd MAE | 剖面 Cd MAE | 基线 P90 | 真实 Cd P90 | 剖面 Cd P90 |
|---|---:|---:|---:|---:|---:|---:|
| constant | 7.82 | 2.04 | 10.21 | 18.24 | 5.97 | 18.89 |
| variable_drag | 4.45 | 2.15 | 16.20 | 8.32 | 8.98 | 20.54 |
| spin | 6.29 | 2.83 | 8.45 | 15.81 | 9.04 | 26.40 |
| wind | 5.55 | 2.84 | 10.07 | 12.80 | 9.35 | 20.17 |
| combined | 4.51 | 2.42 | 17.78 | 9.14 | 7.08 | 22.61 |

- 真实 Cd 在所有机制上都降低 MAE/P90；
- 剖面 Cd 在所有机制上都过校正，说明题目算例的 0.37375 不能当全局 Cd；
- 固定一个全局 Cd（无论 0.22 还是 0.374）都不是好方案。

## 3. 时间误差模型

按机制分层的源级 50/50 划分：50 个 calibration 源（168 条可评分）、50 个 test 源（180 条可评分）。

| 区间方案 | test 覆盖 | 宽度中位 / ms | 说明 |
|---|---:|---:|---|
| 原始后验区间 | 51.1% | 12.46 | 基线 |
| 全局 conformal | 77.8% | 22.16 | ±q_global |
| 分机制 conformal | 76.1% | 20.72 | ±q_mech |
| 全局 additive | **83.3%** | 25.42 | \(\sqrt{h^2+q_{\rm global}^2}\) |
| 分机制 additive | 82.8% | 25.61 | \(\sqrt{h^2+q_{\rm mech}^2}\) |

- 误差项明显改善覆盖，但 **83% 仍低于 90%**；
- 分机制没有优于全局，说明当前每个机制只有 10 个 calibration 源，分位数估计不稳；
- 按机制看，constant 仍只有 67.5%（additive），spin 约 64%–69%；variable_drag/combined 反而接近 100%，宽度偏大。
- 这是“小 calibration 集 + 源间异质性”的典型表现，不是加一个全局常数就能解决。

## 4. 归因

| 来源 | 证据 | 判断 |
|---|---|---|
| 阻力 | 真实 Cd 使 MAE 减半；剖面 Cd 过校正 | **时间误差的主要成分之一** |
| 时间模型 | 误差项使覆盖 51%→83%，但仍不足 90% | **需要，但当前校准样本不足** |
| 机制差异 | constant/spin 仍欠覆盖；variable_drag/combined 过覆盖 | **需要更大分层样本，不能只靠 10 源/机制** |
| 先验 | F1 相对 F0 的时间偏差几乎不变 | 不是时间误差主因 |

## 5. 对下一步的含义

### 5.1 阻力

- 不要采用“把 \(C_D\) 全局固定到 0.37375”的方案；
- 下一步应是 **按案例估计/积分 \(C_D\)**（F-drag），并使用有依据的 \(C_D\) 分布，而不是单一全局值；
- 真实 Cd 消融是 oracle，只说明上限；可部署版本必须从两帧/先验中推断，或按分布积分。

### 5.2 时间

- 需要至少 **100 个 calibration 源**（每机制 20）才能稳定估计分机制误差项；
- 优先用源级 split-conformal 或带有限样本修正的分位数，不要用 10 源/机制的分位数直接发布；
- 在 calibration 不足时，只发布“开发集覆盖表现”，不发布 90% 保证。

### 5.3 模型级顺序

1. 先做 F-drag 的预注册比较：固定 Cd、按案例估计 Cd、按分布积分三档；
2. 时间区间在 F-drag 之后重新校准；
3. 再做独立测试；
4. 不在这之前继续收紧 \(b_y\) 先验。
