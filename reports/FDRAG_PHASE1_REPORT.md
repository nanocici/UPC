# F-drag Phase 1：F-fixed / F-est / F-int 的 profile 比较

日期：2026-11-07（Asia/Shanghai）。
范围：复用第二轮 100 个 development 源、348 个直接过线案例；按预注册网格 `0.15,0.22,0.29,0.36,0.43` 做 F1 五参数 MAP；没有新增后验采样，没有读取 calibration/test。
预注册：[2026-11-07-fdrag-prereg.md](../docs/superpowers/specs/2026-11-07-fdrag-prereg.md)。

## 1. 结论摘要

1. **Phase 1 没有通过筛选。** F-est 的时间 MAE 为 5.43 ms（F-fixed 5.29），F-int 为 5.27 ms；相对改善 <1%，远低于预注册的 20% 筛选线。
2. **阻力 oracle 的收益没有转化为可估计的收益。** 之前的真实 Cd 消融能把 MAE 从 5.34 降到 2.43 ms；但按两帧做 profile 估计时，334 个案例中有 **238 个选中 Cd=0.22**（先验中心），只有 96 个移动到 0.15/0.29/0.36。
3. **空间点误差略差。** F-fixed 的中位二维误差 0.2950 m；F-est 0.3017 m，F-int 0.3055 m；P90 也从 0.628 升到 0.635/0.633。
4. **misfit 略降，但样本少了 14 例。** F-fixed 21.3%；F-est 15.6%，F-int 17.7%；这是 334 个可拟合案例上的比较，不能直接说 F-drag 更稳。
5. **F-int 的 profile 空间椭圆退化。** 5 个层点几乎共线，面积约 \(6\times10^{-7}\ \mathrm{m^2}\)，覆盖 0%；这是 profile-only 的伪区域，不是有效预测区域。Phase 2 的逐层后验采样尚未做，也不应急着做，因为点/时间结果已显示没有收益。
6. **决策：不采纳 F-est/F-int。** F-fixed 保持；F-drag 需要外部 Cd 信息或更强的识别约束，不能靠当前两帧 profile 估计。

## 2. 总体结果

| 方法 | n | 时间偏差 / ms | MAE / ms | P90 / ms | 中位二维误差 / m | P90 / m | misfit |
|---|---:|---:|---:|---:|---:|---:|---:|
| F-fixed | 348 | -0.37 | 5.29 | 14.88 | 0.2950 | 0.6277 | 21.3% |
| F-est | 334 | -1.46 | 5.43 | 14.95 | 0.3017 | 0.6348 | 15.6% |
| F-int | 334 | +0.79 | 5.27 | 13.05 | 0.3055 | 0.6333 | 17.7% |

F-int 的 profile 时间区间：

- 覆盖 78.7%；
- 宽度中位 19.1 ms；
- 仍低于 90%，且这是仅含层间差异的 profile 区间，不含层内后验不确定性。

## 3. 选中 Cd 的分布

334 个可拟合案例：

| 选中 Cd | 案例数 |
|---:|---:|
| 0.15 | 47 |
| 0.22 | **238** |
| 0.29 | 41 |
| 0.36 | 8 |
| 0.43 | 0 |

分机制也以 0.22 为主。  
这说明：在当前 F1 先验和两帧观测下，**Cd 的 profile 后验高度集中在先验中心**；数据没有足够信息把 Cd 推到真实值附近。真实 Cd 中位约 0.23–0.29，但估计器仍回到 0.22。

## 4. 为什么 oracle 有效、估计器无效

之前固定真实 Cd 的消融：

- 共同 334 例，MAE 5.34 → 2.43 ms，P90 15.09 → 8.73 ms；
- 说明阻力确实是时间误差的主要成分。

但 Phase 1：

- F-est 从同一组两帧里选 Cd，仍以 0.22 为主；
- F-int 用先验×profile 权重积分，权重也集中在 0.22；
- 所以 oracle 的 2.4 ms 时间误差无法复现。

结论：

> **“阻力重要”与“阻力可从两帧估计”是两件事。** 当前数据/先验下，Cd 的可识别性不足；直接加一个自由 Cd 或做 profile 积分，不会自动改善 F。

## 5. misfit 的解释

- F-fixed：21.3%；
- F-est：15.6%；
- F-int：17.7%。

F-est/F-int 的 misfit 较低，部分是因为它们只在 334 个“五层都能拟合”的案例上评分，缺失的 14 例可能更难；不能把这当成 F-drag 更稳的证据。按之前诊断，MAP misfit 大部分是 F1 先验张力，LS misfit 约 11.6%；F-drag 没有改变这一点。

## 6. 对 F 模型的含义

- **F1 的空间采纳结论不变。**
- **F-fixed 继续保持时间区间不可发布的状态**；F-est/F-int 没有解决时间问题。
- **不要进入 Phase 2 的逐层后验采样**，除非先解决 Cd 可识别性：
  - 使用外部实测/文献 Cd 分布，而不是 H 真值或题目单例；
  - 或给 Cd 更强的物理先验/约束；
  - 或接受“两帧无法识别 Cd”，把阻力作为时间模型误差的一部分，而不是新增自由参数。
- **时间区间的下一步应回到误差模型/校准**：F-fixed + 模型误差项 + 更大 calibration 集，而不是 F-drag。

## 8. 决策

**Phase 1 不通过；不采纳 F-est/F-int，保留 F-fixed。**

这不是说阻力不重要，而是说：

> 在只有两帧、当前先验和当前 Cd 网格的条件下，Cd 不能被可靠估计；F-drag 的 oracle 收益不可部署。

下一步优先级：

1. 用外部 Cd 分布/先验做一次敏感性，不碰校准/测试；
2. 若仍不可识别，接受 F-fixed，并把阻力作为时间误差模型的一项；
3. 时间区间在更大 calibration 集上校准；
4. 最后独立测试。
