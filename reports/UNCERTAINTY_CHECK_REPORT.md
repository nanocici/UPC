# uncertainty.py 实现与检查记录

日期：2026-11-07（Asia/Shanghai）。本轮实现固定 Cd 的条件后验，未进行 Cd 积分或外部覆盖校准。

## 方法与概率条件

先调用 inverse.fit_case 的 MAP，沿用速度均匀界限、F 圆盘截断高斯及 S 匹配边缘先验、观测误差和给定环境。在缩放参数 q 中，以完整负对数后验数值曲率构造局部尺度；不把纯数据雅可比逆矩阵当成后验。完整曲率不可用时，GN 数据曲率加先验曲率只用于提议形状，仍须正定。

提议为自由度 5 的多元 Student t 混合，默认局部/宽分量质量为 0.85/0.15，宽分量标准差为局部 3 倍；t 的 shape 按 (df-2)/df 转换。多起点找到的不同高权重区域可增设分量。每次固定抽取 2N 个候选，以真实后验密度除以完整混合提议密度修正权重。同一固定 Cd 模型的常数缩放雅可比可约去，不能用省略常数后的量比较模型证据。

域外或观测窗不相容的候选权重为零。观测窗数值失败时重试，仍无法计算似然就停止概率发布；似然已计算而门线传播失败的候选保留原质量。事件分为直接入框、直接越框、先接地、边界、未决和传播失败；直接入框概率同时给出含未判定质量的界限。

直接过平面条件与入框条件的位置分别汇总。评分点使用条件均值，最可能位置使用等面积格网的最高质量单元。椭圆由加权总体协方差及平方马氏距离的加权 90% 分位数构造，不假设门线分布高斯，不将模型内概率质量当成外部覆盖保证。

## 检查与证据范围

项目环境：macOS，Python 3.13.13、NumPy 2.5.4、SciPy 1.18.1、Matplotlib 3.11.2。Windows 命令已提供，未在 Windows 实机运行。

新增 tests/test_uncertainty.py 的 18 项检查通过，项目合计 95 项检查通过。包括对数权重稳定归一化、ESS、加权分位数、质量格网众数、混合提议修正恢复解析正态均值/方差、已知二次型 Hessian、先接地/失败质量保留、手算区域面积、奇异区域拒绝、全部先接地、后验与 MAP 目标一致、边界零密度、似然失败停止、已知权重的预测失败保留、随机复现、无效设置、不可用输入标签、评价接口，以及均值稳定不自动意味着众数稳定。

测试中发现 scipy 一维 t 变元返回 (N,) 而多维返回 (N,d)，原提议包装对一维处理错误。最小解析分布测试复现后改为显式 (N,d) 形状，回归检查已通过。集成单元测试使用明确放宽的少样本阈值控制耗时，未用这些阈值替换正式算例设置。

正式算例使用默认总体 ESS≥300、条件 ESS≥100，N→2N 的事件概率差≤0.02、均值位移≤0.05 m、区域相对面积差≤15%，未知质量≤1e-6。众数稳定另要求格网/采样移动在工作档位 0.20 m 内，不能与均值诊断混为一谈。局部高斯标记只检查曲率和边界，不证明全局形状。

## 本轮题目条件算例

命令：

```bash
.venv/bin/python code/uncertainty.py --model both --plot
```

输出 results/uncertainty_example。每模型 N=2000，实际固定提议 4000；Cd=0.22、静风、位置标准差 0.01 m、相同共享先验。候选参数/权重/密度全部保存为 CSV，汇总和诊断保存为 JSON。以下为当前工作假设下的模型内结果：

| 项目 | S | F |
|---|---:|---:|
| 总体 ESS | 2938.28 | 2739.24 |
| 条件均值 Y / m | 2.90443 | 2.89807 |
| 条件均值 Z / m | 1.90800 | 1.94884 |
| 90% 模型内椭圆面积 / m² | 0.16472 | 1.74476 |

S 的名义众数格中心约 (2.79583, 1.88083) m；F 的名义最高质量格中心约 (2.79583, 1.77917) m，但后者随采样量仍不稳定，只能保留为有限分辨率候选峰。当前格宽约 0.10167 m，不将这些格中心解释为厘米级峰值定位。

两模型均通过均值、区域和事件概率采样检查；F 的 success=true 不表示众数稳定，message 与 mode_stable 已明确标注。可以增加样本并复核格网以继续检验该峰值；不能因为均值稳定便声明最可能点已收敛。候选图已经视觉检查，显示均值、格网位置、门框与未校准区域。

上述概率完全条件于固定 Cd、环境、先验及误差。S 排除竖向有效气动力，其区域更窄不证明真实预测更好。区域大小、实际覆盖及有效预测比例需在独立机制和观测条件下联合评价，不能从这一算例决定模型优劣。

## 交接与未完成内容

uncertainty_observation 返回 evaluate 的共同预测格式，point_kind 为 mean，始终声明名义区域质量。诊断未过时返回 failure，观测缺失时 unavailable，均保留评价分母。没有足够条件 ESS 时不伪造门线位置；有未知事件质量时单一 goal_probability 留空，界限在日志中保留。

本轮未批量计算开发组区域覆盖率，未开启校准/测试组评价；尚缺阻力重拟合剖面、Cd 积分、先验/环境/机制敏感性、外部数据核查及区域校准。当前 API 和 CLI 可接入这些阶段，但程序通过不等于研究验证完成。
