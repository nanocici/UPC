# data.py 实现与检查记录

日期：2026-11-07（Asia/Shanghai）。本轮从共同设置出发，实现独立测试数据生成；不继承历史反演数字。

## 实现范围

`code/data.py` 独立实现 H 运动方程、DOP853 求解与事件，不导入 `physics.py` 或 `inverse.py`。支持常系数对照、随雷诺数变化的阻力、自旋相关横向力、给定风和组合机制。升力系数乘以单位自旋与单位相对速度的叉积，零自旋、平行自旋与零相对速度均有相容极限。

变阻力采用平滑过渡曲线，自旋系数采用饱和曲线；曲线数值、速度、自旋、有效横向力与风的抽样范围均明确记录为压力测试设置，尚未据球型实验标定。不能将由此得到的模拟成绩直接称为实测精度。

生成干净球路后，支持独立或跨帧等相关高斯误差、纯舍入和无误差模式。同源射门的所有噪声副本共用一个开发/校准/测试分组。先接地、缺少第二帧、未决和数值失败均保留记录，不按进球、过平面或成功取得两帧筛选总体。

观测、已知环境与测量误差设置写入 `observations`；真实气动参数、环境、种子、完整轨迹和事件写入 `truth`。加载观测的函数拒绝真值格式，读取不可用两帧案例时显式报错。默认未知风场景的预测输入使用名义零风，真实风不泄漏；可另建已知风对照。

另实现 `load_trajectory_csv`，要求调用者明确长度、时间单位，帧号配套 FPS。它只做格式与单位读取，未完成任何外部项目的起飞时刻、坐标方向、球门或早期信息独立性核验。

## 检查结果

macOS 项目环境：Python 3.13.13、NumPy 2.5.4、SciPy 1.18.1。Windows 使用方法已提供，本轮未在 Windows 实机执行。

新增 `tests/test_data.py` 的 22 项检查通过，加上既有 21 项运动检查，合计 43 项通过。范围包括：

- 独立常系数生成器与 F 的共同方程极限一致；无空气力对照解析重力解。
- 变阻力曲线有界；零自旋、平行自旋、零相对速度和三维自旋相对功平衡。
- 生成端收紧容差和步长后的事件与交点收敛；先接地、初始接触、边界、未决与数值失败。
- 高斯误差复现、完整相关误差、舍入界限、无误差与缺测保留。
- 同源副本不跨组；重复运行复现；输入与真值字段分离，未知风隐藏。
- JSONL 保存/读取、拒绝覆盖、拒绝真值输入、不可用记录显式拒绝。
- CSV 长度及帧率转换、重复时间拒绝和错误设置检查。

执行命令：

```bash
.venv/bin/python -m unittest discover -s tests -v
```

## 本轮生成的流程示例

先对 20 条源射门生成计时，本机约 0.342 s；仅指合成数据生成，不包含反演或概率传播，不代表在线预测时延。

随后运行：

```bash
.venv/bin/python code/data.py --sources 60
```

输出为 `data/synthetic_demo`，随机种子取共同配置的 `20261107`：

| 项目 | 数量 |
|---|---:|
| 独立源射门 | 60 |
| 开发 / 校准 / 测试源射门 | 36 / 12 / 12 |
| 含四档噪声的观测记录 | 240 |
| 首先过门线平面（包括门框外） | 47 |
| 首先接地 | 13 |
| 不具备完整两帧的源射门 | 2 |

缺少完整两帧的 2 条源射门及其 8 条噪声副本仍被保存。该示例用于程序对接，校准和测试独立源样本各 12 条，不足以单独支持可靠覆盖率结论，也未评价任何预测器。

## 复现与交接

种子、抽样范围、求解设置、事件统计及分组数量见示例的 `manifest.json`；每个源射门的实际参数、源种子和噪声种子见对应 `truth/*.jsonl`。若要重新生成，指定一个新的输出目录，程序会拒绝覆盖旧目录。

乙仅使用 `observations`，通过 `observation_case` 转为共同 `ObservationCase`，并将 `known_environment` 显式传给反演。丙评价时通过 `source_id` 关联真值，所有覆盖率、误差与不可用比例均须注明分母。反演、区域校准、G/A/S/F 比较、实测核查和观测设计扩展仍待后续实施。
