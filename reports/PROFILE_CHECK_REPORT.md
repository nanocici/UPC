# 阻力重拟合剖面：实现、检查与算例结果

日期：2026-11-07（Asia/Shanghai）。本轮只处理用户给定的题目算例，没有访问开发、校准或测试组，没有运行阻力积分或新的概率传播。

## 实现与复现

新增 `code/profile.py`，复用 `inverse.fit_case` 和 `physics.simulate`，不改动既有模型及共享默认值。命令从项目根目录执行：

```bash
.venv/bin/python code/profile.py --output results/profile_example --plot
```

Windows PowerShell：

```powershell
.\.venv\Scripts\python.exe code\profile.py --output results\my_profile --plot
```

已有输出目录拒绝覆盖；复跑需换 `--output`。Mac 项目环境已实际运行；Windows 命令未在实机验证。

首轮设置为静风、现有球体和空气参数、六坐标独立高斯工作误差 `sigma=0.01 m`。在工作范围 `[0.08,0.55]` 取 25 个等距 Cd，再补入 0.22，共 26 层。S/F、LS/MAP 各运行一遍，每层三个独立起点，共 104 个基础拟合任务。阻力范围、误差和先验仍为工作设置，尚未经外部数据核验。

- LS 的 `data_chi_square` 才构成纯数据剖面 R(c)；CSV 的 `pure_data_profile_R` 仅在 LS 行填写。
- MAP 记录完整目标、数据卡方和先验罚项。目标为半数据卡方加先验，不能拿 MAP 解的数据卡方冒充纯数据极小值。
- 另保存 52 条前向对照：分别固定 S/F 在 Cd=0.22 的 MAP 初速度与横向参数，仅改变 Cd。该对照不重新拟合。
- 所有拟合保留多起点日志、残差、参数、雅可比和边界诊断、首事件与耗时。拟合成功和传播事件分别保存；先接地、未决或失败不发布门线 Y/Z/T。

## 程序与数值检查

新增 `tests/test_profile.py` 的 9 项检查，完整项目 111 项检查通过：

```bash
.venv/bin/python -m unittest discover -s tests -v
```

新增检查涉及节点/名义值、LS/MAP 目标区分、已知 S 球路恢复、重拟合残差不劣于固定参数扫描、固定扫描不重拟合且保留其他参数、接地/失败不伪造门线坐标、失败名义层保留全部前向记录、复核识别变化解、输入校验及已有结果保护。

实际 104/104 个基础任务至少一个起点收敛，最终均首次正向过门线，无参数边界命中。这里 event=`goal` 表示过平面事件，不代表经校准的入框概率。

按事先记录的规则，对端点、名义层、目标和 Y/Z/T 极值、失败/边界、事件变化和大于 0.1 m 的相邻层位置跳变选点。实际选中每组 Cd=0.08、0.22、0.37375、0.55，共 16 层；每层改用九起点，积分相对/绝对容差收紧十倍，最大步长减半。

16/16 层通过既定复核要求：同事件、目标差不超过 `1e-5*max(1,abs(base_objective))`、门线位移不超过 0.001 m、时间变化不超过 1e-5 s。实际最大绝对目标差约 5.13e-10，最大门线位移约 1.04e-6 m，最大时间差约 1.69e-8 s。它们说明选定层对这次数值和起点调整稳定，不证明全局唯一或真实预测精度。

本机全流程约 28.96 s，含基础拟合、前向扫描、加严复核、保存和绘图；不构成在线运行时间保证。

## 本轮算例结果

下表为整个工作阻力网格上、每层各自重新拟合后的最小—最大值，全部是轨迹点解。未按观测相容性阈值筛选，不是置信区间。

| 模型/目标 | Y 范围 / m | Z 范围 / m | T 范围 / s | 数据卡方范围 |
|---|---:|---:|---:|---:|
| S / LS | 2.642091–2.644278 | 1.828648–1.928067 | 0.372910–0.417240 | 0.042141–3.100759 |
| S / MAP | 2.888895–2.890072 | 1.832361–1.933494 | 0.374757–0.419644 | 0.323196–3.380003 |
| F / LS | 2.640211–2.642478 | 1.921546–2.020913 | 0.373443–0.417899 | 0.000737–3.059195 |
| F / MAP | 2.886920–2.888051 | 1.876481–1.977948 | 0.374997–0.419938 | 0.290336–3.346918 |

各目标在当前离散网格的最小值都出现在 Cd=0.37375。这只是网格极小点，本轮没有加密搜索真实极小值，也没有据此声称已识别真实阻力或建立阻力置信区间。

名义 Cd=0.22 的点解如下：

| 模型/目标 | Y / m | Z / m | T / s |
|---|---:|---:|---:|
| S / LS | 2.643581 | 1.901118 | 0.385331 |
| S / MAP | 2.889213 | 1.906102 | 0.387329 |
| F / LS | 2.641759 | 1.993950 | 0.385899 |
| F / MAP | 2.887224 | 1.950438 | 0.387584 |

在本算例、本模型及固定误差/先验下，改变阻力并重拟合使 Y 变化约 1–2 mm、Z 变化约 0.10 m、T 变化约 0.045 s。这只是对阻力这一因素的条件敏感性，不能据此声称横向预测具有毫米级总精度。

在同一名义 Cd 下，MAP 相对 LS 的 Y 位移为 S 约 0.24563 m、F 约 0.24547 m，明显大于各自阻力剖面的 Y 变化。说明在现有工作设置下，加入横向先验对横向点预测有实质影响；两种目标并不应混用。尚未进行先验尺度和观测误差档位的完整敏感性实验，不能把该位移解释为标准差。

## 结论范围与下一步

本轮完成了阻力重拟合剖面及固定参数前向对照，不能把全区间范围解释为 90% 区域，也不能将各层最佳轨迹等权混合为概率后验。S/F 的最终选型、阻力积分、批量覆盖、区域校准及独立测试均未完成；既有 F 后验众数不稳定的问题没有因本轮点剖面而解决。
