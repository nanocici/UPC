# evaluate.py 实现与检查记录

日期：2026-11-07（Asia/Shanghai）。本轮实现评价程序，S/F 反演及不确定性仍未实现。

## 实现范围

`code/evaluate.py` 接收观测清单、每个源射门的真值和按共同格式提交的预测，验证 `case_id`、`source_id`、`split`，拒绝重复、错组或找不到真值的记录。每个方法以全部观测清单展开；漏交预测记为 `missing`，求解失败、观测不可用、先接地和未决分别保留。

可评价门线二维误差、到达时间绝对误差、椭圆区域覆盖率和面积、直接入框概率 Brier 分数。点预测基线未提供概率时，区域与 Brier 指标为 null。声称提供概率区域的方法，即使失败或缺少区域仍以真实直接过平面案例为覆盖率分母；奇异或其他无效区域计入漏覆盖。另报告完整观测子集，避免隐藏数据本身不可用的比例。

统计区分噪声观测案例数与独立源射门数。95% 百分位区间按 `source_id` 整组重采样，保留组内噪声副本相关性。提供噪声/机制分层表，以及共同可评分案例上的方法配对比较；配对比较是条件比较，必须连同各方法的输出比例与失败率解读。

输出 summary.json、metrics.csv、per_case.csv、可选预测 JSONL 和 PNG。CSV 为带 BOM 的 UTF-8。既有输出目录拒绝覆盖。

本模块不替代区域校准、模型选择或配置冻结；未来不确定性模块须传入实际输出的评分点和区域定义。区域接口使用二维中心、正定协方差及平方马氏距离阈值，面积为 pi × threshold × sqrt(det(covariance))。单条拟合轨迹点的默认标签为 point_estimate，不自动称为后验均值或众数。

## 本轮检查

macOS 项目环境：Python 3.13.13、NumPy 2.5.4、SciPy 1.18.1、Matplotlib 3.11.2。Windows 命令已提供，本轮未在 Windows 实机运行。

新增 tests/test_evaluate.py 的 19 项检查通过，项目合计 62 项检查通过。核查内容包括：

- 手算的二维欧氏距离、时间误差、椭圆面积及边界覆盖。
- 缺预测、求解失败和无效区域保持覆盖率分母；观测不可用子集另报。
- 未声明概率区域的点预测覆盖率为 null，声明区域但无输出时计漏覆盖。
- 手算 Brier 分数、明确与未决事件标签、缺概率计数。
- 重复或错配预测、缺真值、不同数据划分、混用评分点定义、非有限点值的拒绝。
- 源射门重采样的副本相关性和复现，共同样本配对比较，噪声/机制分层。
- 空指标以 null 序列化、预测读写、输出目录拒绝覆盖、G/A 无真值输入生成。

测试命令：


## G/A 开发组流程示例

默认使用 data/synthetic_demo 的开发组，先仅从公开观测生成 G/A 预测，再读对应真值评价。输出目录为 results/evaluation_demo。没有开启校准组或独立测试组的模型评价。

| 项目 | A 恒加速度 | G 仅重力 |
|---|---:|---:|
| 观测案例数 | 144 | 144 |
| 独立源射门数 | 36 | 36 |
| 完整观测不可用案例数 | 8 | 8 |
| 真值直接过门线案例数（含门外） | 112 | 112 |
| 点误差可评分案例数 | 94 | 110 |
| 各自可评分子集二维误差中位数 / m | 0.8500 | 0.3595 |
| 区域覆盖率 | 未提供区域，null | 未提供区域，null |

上述两组中位数对应不同有效子集，不能单凭它们证明模型优劣。配对表在 93 个共同可评分观测案例、28 条源射门上计算 A 减 G 的中位误差差，约为 0.5027 m；300 次整组重采样的 95% 百分位区间约为 [0.2773, 0.7211] m。此结果仅描述当前生成机制和开发数据，未验证主模型，也未用于独立测试结论。

示例图 point_metrics.png 已进行视觉检查；图中分别展示条件误差及全部真实过平面案例中的点预测提供比例，完整分母仍以 CSV/JSON 为准。
