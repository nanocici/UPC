# 独立测试：F1 + 空间校准 + 冻结时间模型

日期：2026-11-07（Asia/Shanghai）。
范围：新 200 源，100 calibration / 100 test，每类机制各 20/20；F1 固定 \(C_D=0.22\)；800 个任务、3,028,000 次提议、2,143.7 s。时间 q 使用此前冻结值，不在本数据上重调。

## 1. 数据

| 项目 | calibration | test |
|---|---:|---:|
| 源 | 100 | 100 |
| 每机制 | 20 | 20 |
| 真实直接过线源 | 84 | 77 |
| 直接过线观测 | 336 | 308 |
| 失败/缺失 | 2 个直接案例失败 | 0 |

## 2. 空间区域校准

在 calibration 上对椭圆做 split-conformal 阈值校准：

\[
q_{\rm cal}=3.0835,\quad \text{rank}=301/334
\]

| 方法 | 覆盖（校准） | 覆盖（test） | test 源级 95% 区间 | 面积中位（校准） | 面积中位（test） |
|---|---:|---:|---|---:|---:|
| 原模型内区域 | 95.83% | 95.78% | [93.51%, 97.73%] | 1.285 m² | 1.475 m² |
| **校准区域** | **89.88%** | **88.64%** | **[84.74%, 92.21%]** | **0.878 m²** | **0.983 m²** |

- 校准把 test 面积从 1.475 降到 0.983 m²（约 **-33.3%**）；
- test 覆盖 88.64%，略低于名义 90%，但源级 95% 区间 [84.74%, 92.21%] 包含 90%；
- calibration 覆盖 89.88%，说明校准步骤本身正常；
- 这是**独立 test 的一次性评价**，没有回调 q_cal。

分机制（校准区域，test）：

| 机制 | n | 覆盖 |
|---|---:|---:|
| constant | 68 | 88.2% |
| variable_drag | 48 | 91.7% |
| spin | 64 | 90.6% |
| wind | 64 | 90.6% |
| combined | 64 | **82.8%** |

combined 仍偏低；不能因为总体 88.6% 就宣布所有机制都达到 90%。

## 3. 时间区间（冻结 q）

时间 q 固定为 15.1889 ms：

| 项目 | calibration | test |
|---|---:|---:|
| 覆盖 | 97.01% | **96.10%** |
| 源级 95% 区间 | [94.35%, 99.11%] | [91.56%, 99.68%] |
| 宽度中位 | 33.06 ms | 33.68 ms |
| 时间误差中位 | 5.43 ms | 5.46 ms |

时间模型在独立 test 上仍然覆盖约 96%，没有崩；但偏保守，宽度约 34 ms。  
时间点误差没有改善，仍是约 5.5 ms。

## 4. 点误差

test：

- 中位二维误差：**0.3183 m**；
- P90：**0.6145 m**。

与之前 development 的 0.295–0.318 m 同量级；F1 的点精度没有因校准改变。

## 5. 结论

1. **空间校准有效但略欠覆盖**：test 88.6%，源级区间包含 90%，面积缩小 33%；combined 机制 82.8% 是明确弱点。
2. **时间模型通过独立 test**：96.1% 覆盖，源级下界 91.6%；偏保守，宽度 33.7 ms。
3. **点误差不变**：约 0.318 m/P90 0.615 m；校准只改区域，不改点。
4. **失败**：test 直接过线无失败；calibration 有 2 个失败，保留。
5. **真实数据仍缺**：这是合成 H 机制的独立 test，不是实测。

## 6. 对冻结版本的更新建议

- 时间：继续使用冻结 q=15.1889 ms；
- 空间：将最终算例区域改为**校准阈值 3.0835**，对应区域面积约 **0.766 m²**（原模型内 1.1668 m²）；保留原区域作为诊断；
- 主点平滑峰 (2.875,1.925) m、原始格网众数、辅助均值不变；
- 在最终报告中写明：test 覆盖 88.6%，combined 82.8%，未达到严格 90%，不能称“完全校准”。
