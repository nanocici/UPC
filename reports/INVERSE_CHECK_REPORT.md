# inverse.py 实现与检查记录

日期：2026-11-07（Asia/Shanghai）。本轮重新实现固定阻力反演，以下数字均来自本轮代码，不继承旧文档结果。

## 方法与输出

`fit_case` 支持 S 的四参数及 F 的五参数条件反演，固定 Cd，使用缩放、多起点 SLSQP、速度界限与横向圆盘约束。MAP 使用已声明高斯误差和横向工作先验；LS 单独去掉先验罚项。F 先验是圆盘内二维高斯，S 使用其 b_z 边缘，包含 erf 积分因子。罚项在各自零点归零，不据此计算模型证据。

优化反复调用 physics.simulate，但仅计算至最后观测时刻；收敛后另作完整传播。初值来自重力拟合，若过早接地则尝试修复竖直初速度。记录所有起点状态、观测窗不相容/数值失败计数、缩放纯数据雅可比、秩、条件数和边界命中。局部满秩不证明参数精确或全局唯一。

只接受收敛且观测窗可计算、满足约束的候选。没有收敛候选时导出失败，不将未收敛参数伪装成有效预测。第二帧之后落地保留为可接受拟合，最终没有直接门线点；观测窗反演成功与最终传播成功分别记录。观测不可用记录仍输出，不改变评价分母。

批量只读取 observations，按记录提供的总标准差及跨帧相关构造正定高斯协方差。纯舍入、无噪声精确约束与完全相关奇异似然尚未实现；必须显式指定正高斯 sigma 工作假设才能按该近似处理，日志保留覆盖设置。程序不读取 truth，不根据生成机制调初值或先验。

## 程序检查

本机 macOS：Python 3.13.13、NumPy 2.5.4、SciPy 1.18.1。Windows 命令已提供，未在 Windows 实机验证。

新增 tests/test_inverse.py 的 15 项检查通过，项目累计 77 项检查通过。内容包括：S/F 已知参数同模型 LS 恢复、MAP 目标分解、强先验收缩、S/F 边缘先验关系、相关噪声协方差与白化、速度/圆盘约束、第二帧后落地、无收敛与数值失败处理、输入校验、显式噪声覆盖、评价接口、重复性与多起点。

对接期间发现不可用分支漏设 point_kind，导致同方法被误判为混用定义。已用最小案例复现，补上回归检查并修复；成功、失败和不可用记录统一为 map_trajectory 或 ls_trajectory。

执行命令：

```bash
.venv/bin/python -m unittest discover -s tests -v
```

## 当前限制与下一步

尚无参数后验、门线众数、预测区域、直接入框概率、阻力重拟合剖面、阻力积分或区域校准。同模型恢复检查验证实现，开发组异机制表现仍受生成设置限制；独立实测和冻结后的测试评价未完成。

下一步的 uncertainty.py 可复用 fit_case、观测协方差和纯数据雅可比，但不能将数据雅可比逆矩阵直接冒充带先验、带约束的完整后验。参数、观测误差和模型情景的贡献须按建模报告处理。

实现参考：[SciPy SLSQP 官方文档](https://docs.scipy.org/doc/scipy/reference/optimize.minimize-slsqp.html)。
