# 最终冻结候选：F1 + 全局 additive 时间模型

状态：**冻结候选**（freeze candidate），不是最终外部验证。
日期：2026-11-07（Asia/Shanghai）。
适用：UPC 2026 Problem B 指定算例与后续独立测试；改变以下任何一项都必须新建版本，不能覆盖本冻结。

## 1. 轨迹与空间模型

| 项目 | 冻结值 |
|---|---|
| 模型 | F：重力 + 二次阻力 + 有效横向力 \((0,b_y,b_z)\) |
| 阻力 | 固定 \(C_D=0.22\) |
| \(b_y\) 先验 | 圆盘内高斯，尺度 0.10 |
| \(b_z\) 先验 | 圆盘内高斯，尺度 0.20 |
| 圆盘半径 | 0.50 |
| 观测误差 | 每轴独立高斯，\(\sigma=0.01\) m |
| 环境 | 静风，\(m=0.43\) kg，\(R=0.11\) m，\(\rho=1.20\) kg/m³ |
| 采样 | 基础 N=2000，实际 4000 次提议；3 个优化起点；无自适应加倍 |
| 空间输出 | 条件均值 + 名义 90% 模型内区域；不发布稳定众数 |

依据：第二轮 F0/F1 预注册比较；F1 五项空间条件全部通过，区域面积中位 1.352 m²、覆盖 94.54%。见 [ROUND2_SELECTION_REPORT.md](../../reports/ROUND2_SELECTION_REPORT.md)。

## 2. 时间模型

时间区间使用 **全局 additive 误差项**：

\[
T \in \left[\hat T \pm \sqrt{h^2+q^2}\right],
\]

其中 \(h\) 是原后验 90% 区间半宽，\(q=0.0151889103\) s（15.19 ms）。

- \(q\) 来自 200 源实验：100 calibration / 100 test，每机制各 20；F1 固定 Cd；
- test 覆盖 94.9%，源级 bootstrap 95% 区间 [90.7%, 98.1%]；
- 区间宽度中位 33.7 ms；
- 这是开发集 calibration/test 结果，不是最终独立测试。

见 [TIME_MODEL_200_REPORT.md](../../reports/TIME_MODEL_200_REPORT.md)。

## 4. 适用范围与限制

- 空间区域为**模型内名义 90%**，未做外部区域校准；不能称为真实 90% 覆盖保证。
- 时间区间为**开发集校准**；独立测试尚未完成。
- 众数不稳定；主点使用条件均值，不能把众数候选当稳定峰值。
- 只适用于静风、固定 \(C_D=0.22\)、给定 \(\sigma=0.01\) m 和 F1 先验；换环境/误差/先验需重新校准。
- 不包含真实足球数据、门将可达性、球半径几何修正或在线延迟保证。
- S 未参与冻结；F0 仅作历史对照。

## 5. 变更控制

- 本文件冻结后，任何模型/先验/误差/时间 q 的改动都必须新建版本并在独立数据上重新评价。
- 独立测试只评价本冻结版本，不用测试结果回调 q 或空间区域尺度。
- 若独立测试时间覆盖不在 85%–95%，记录失败并保留版本，不临时放宽。
