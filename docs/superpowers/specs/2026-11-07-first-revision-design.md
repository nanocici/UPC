# 第一轮修订（用户已授权执行）

目的：修复已复现的极小sigma伪收敛、整体发布开关和有限采样失败，再比较有限F先验候选。保留原研究数据；校准/测试不读取。

方案：保留SLSQP及真实似然/先验，统一乘正常数缩放完整目标（不改变MAP），认证可行性和约束KKT残差。拒绝仅optimizer.success的证据。相比替换求解器，该方案直接针对已知数值尺度原因。

输出：事件概率、条件均值、预测区域分别认证，结果记录有效性；总体success保留联合语义，公共预测允许已认证部分，缺区域照计漏覆盖。未知事件质量不删除、不当作接地；仅发布已认证的概率或界限。

预算：基准4000提议；修订实验允许两次加倍至8000/16000，固定提议、追加随机样本，所有权重按完整目标/混合提议重新归一。保留每个阶段诊断。阈值不放宽。固定传播最长时间仍4s；未决质量保留为未决，避免以改变物理范围掩盖失败。

先验：F圆盘内高斯允许分方向尺度，by（竖向力）为0.20/0.10/0.05，bz（侧向力）保持0.20；S使用对应F的bz边缘（积分截断宽度使用by尺度）。原默认各向同性先验不自动改成某一候选。

验证：先建立极小sigma与伪成功回归测试，恢复原60条干净轨迹；复跑60条匹配先验公开输入，保持种子及原阈值，比较旧封存预测。通过数值恢复后，开发组比较F三候选（源组配对、点误差、覆盖、面积、有效输出和成本）。只按开发证据给候选判断，不冻结/校准，不以采样稳定替代众数稳定。
