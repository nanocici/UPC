# F-drag 预注册：F-fixed / F-est / F-int

状态：Phase 1 冻结稿。日期：2026-11-07（Asia/Shanghai）。
范围：复用第二轮 100 个 development 源、400 条观测；calibration/test 不读取；S 不参与。
目的：在不改变 F1 空间采纳结论的前提下，比较三种阻力处理对时间、空间点误差、覆盖与 misfit 的影响。

## 1. 三种处理

| 名称 | \(C_D\) 处理 | 说明 |
|---|---|---|
| F-fixed | 固定 0.22 | 现有 F1 结果，作为基线 |
| F-est | 在预注册网格上按案例选一个 Cd | profile MAP；不是联合 6 参数拟合 |
| F-int | 在预注册网格上按权重积分 | profile posterior 近似；不是完整 5 参数边缘化 |

共同设置：F 模型、\(b_y\) 先验 0.10、\(b_z\) 先验 0.20、固定观测误差、3 起点、相同环境。
Cd 网格：`0.15, 0.22, 0.29, 0.36, 0.43`（5 层，覆盖生成分布的 0.15–0.45 主体）。
Cd 先验：截断在 `[0.08, 0.55]` 的 \(N(0.22, 0.10)\)，与共享配置一致；不使用真值。

### F-est

对每个案例、每层做 F1 的五参数 MAP，记录完整目标 \(J_j\)（含 \(b\) 先验）。
选择

\[
j^\star=\arg\max_j\left[\log p(C_D^{(j)})-J_j\right].
\]

报告选中层的 Cd、Y、Z、T；不把网格层中心当成连续精确估计。

### F-int

同一组层，权重

\[
w_j=\frac{p(C_D^{(j)})\exp(-J_j)}{\sum_k p(C_D^{(k)})\exp(-J_k)}.
\]

这是 profile posterior 近似：层内的 5 参数不确定性没有重新积分。用于 Phase 1 筛选；
Phase 2 若进入覆盖评估，必须在每层做后验采样并按层权重合并。

## 2. Phase 1 指标

- 时间：有符号偏差、MAE、P90；F-int 用层的加权 5%–95% 分位数作为 profile 时间区间，报告覆盖与宽度；F-est 只报告点误差。
- 空间：Y/Z/二维点误差的中位数与 P90；F-int 用层点的加权协方差构造 90% profile 椭圆，报告覆盖与面积；F-est 只报告点误差。
- misfit：选中层/F-int 加权层的 `chi²/dof`；报告 >4 比例；不把 MAP misfit 单独当模型错设。
- 失败：拟合失败、非 goal 事件、无点；保留分母。
- 成本：实际拟合次数、墙钟。

Phase 1 的覆盖是 **profile-only**，会低估层内不确定性；不能与 F-fixed 的后验覆盖直接等价。
Phase 2 才对 F-est/F-int 做逐层后验采样和正式覆盖比较。

## 3. 判定

Phase 1 只做筛选，不冻结 F-drag：

- F-est/F-int 的时间 MAE/P90 必须明显低于 F-fixed（建议至少 20% 相对下降）；
- 空间点误差不得明显恶化（中位数增加不超过 0.02 m，P90 不超过 0.05 m）；
- misfit 不得明显恶化；
- 若时间改善但空间恶化，标记“取舍”，不直接采纳；
- profile 覆盖只作描述，不据此宣布已校准。

只有 Phase 2 的逐层后验覆盖通过后，才讨论 F-drag 是否替换 F-fixed。

## 4. 预算与数据

- 348 个直接过线案例 × 5 层 × 3 起点 = 5220 次基础拟合；
- 不新增后验采样；不读取 calibration/test；
- 若 Phase 1 显示 F-int 有希望，Phase 2 在预注册子集（建议 100 个直接案例）上做逐层采样。

## 5. 明确不做

- 不把 0.37375 当全局 Cd；
- 不用真值 Cd 作为可部署输入（只作 oracle 参考）；
- 不因为“加了阻力”自动认为更好；
- 不改变第二轮 F1 的空间采纳结论；
- 不打开 calibration/test。
