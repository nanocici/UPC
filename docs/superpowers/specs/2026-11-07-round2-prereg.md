# 第二轮预注册：F0/F1 选择与 S/F 结构对照

状态：**冻结候选稿**。本文件在生成任何新源射门之前定稿；新数据、校准集和测试集均未读取。
日期：2026-11-07（Asia/Shanghai）。
适用范围：下一轮开发验证。本文不改变既有模型、默认先验或采样阈值；只冻结选择规则、数据分母、缺失口径和报告方式。

## 0. 目的与顺序

目的：在新增 development 数据上，预先规定如何比较

- F0：F 模型，`b_y` 先验尺度 0.20，`b_z` 先验尺度 0.20；
- F1：F 模型，`b_y` 先验尺度 0.10，`b_z` 先验尺度 0.20；
- S：S 模型（`b_y=0`），使用 **F0 的 `b_z` 匹配边缘先验**。

其中 S/F0 用于结构消融，F0/F1 用于先验调整比较。F1 改变竖向尺度后，圆盘截断也会轻微改变 `b_z` 的边缘分布，因此 **F1/S 不能解释为完全纯粹的“只释放 `b_y`”比较**。

执行顺序固定为：

1. **A 审计**：复用现有结果，完成假设依赖审计（见 `reports/ASSUMPTION_AUDIT_REPORT.md`）。
2. **B 冻结**：本文件定稿并记录哈希；此后不得因新结果修改门槛、分母或失败定义。
3. **C 既有样本检查**：复用现有众数候选，按固定格网、带宽和竞争峰定义检查原因；C 的发现不得用于事后修改 B。
4. **新源实验**：按本文件生成 100 个 development 源并运行 1200 个任务。
5. 评估、报告、决定是否采纳 F1；校准/测试继续关闭。

40–60 分钟只是按现有吞吐的粗估，不是完成时限；不以时限为由减少任务、放宽诊断或删去失败案例。

## 1. 数据分母与生成口径

### 1.1 新数据

- 新增 **100 个 development 源**；五类机制各 **20 个**：`constant`、`variable_drag`、`spin`、`wind`、`combined`。
- 每个源生成四档独立高斯位置误差：`0.005, 0.010, 0.020, 0.050` m，形成 **400 条观测**。
- 三个方法 × 400 条观测 = **1200 个任务**。
- 生成使用 `data.build_dataset(..., split_fractions=(1, 0, 0))`，使 100 个源全部进入 development；不得使用默认 `(0.6, 0.2, 0.2)` 后再把 development 当 100 源。
- 生成种子固定为 **20261108**；机制顺序沿用 `data.MECHANISMS`，`source i` 的机制为 `MECHANISMS[i % 5]`，因此 100 源恰好每类 20 个。
- 真值、生成参数、机制标签和源种子只用于封存后的评价；预测任务只取得公开观测与允许的环境。
- 新数据中的 calibration/test 文件即使存在也不读取；原有 `data/synthetic_demo` 的 calibration/test 继续关闭。
- 不按入框、过线、接地或观测可用性筛选源；不可用观测保留在任务和评价分母中，不用新源替换。

### 1.2 方法设置

三个方法使用完全相同的：

- 固定阻力 `C_D = 0.22`；
- 观测协方差：每条观测给定的高斯标准差与跨帧相关设置；
- 环境：观测记录中的已知环境；未知风按记录处理，不从真值补入；
- 优化起点数 `starts = 3`；
- 基础样本 `base_samples = 2000`，固定提议总数 **4000**；
- `max_sample_doublings = 0`：不做自适应追加，不因诊断失败临时加样本；
- 求解器、容差、事件定义、区域质量 0.90 和格网宽度沿用共享配置；
- 每个案例的 Monte Carlo 种子固定为 `20261108 + observation_index`，三个方法使用同一整数种子；这不宣称生成相同参数候选。

任何任务在固定 4000 次提议下未通过采样/事件/区域诊断，均按失败保留，不重试、不放宽阈值。实际提议数和墙钟耗时按方法分别报告。

### 1.3 先验

| 方法 | `b_y` 先验 | `b_z` 先验 | 备注 |
|---|---|---|---|
| F0 | 圆盘内高斯，尺度 0.20 | 圆盘内高斯，尺度 0.20 | 基线 |
| F1 | 圆盘内高斯，尺度 0.10 | 圆盘内高斯，尺度 0.20 | 面积缩小候选 |
| S | 固定 0 | F0 的 `b_z` 匹配边缘先验 | 结构对照 |

圆盘半径、速度范围和其他共享先验不变。S 的截断积分使用 F0 的 `b_z` 尺度与圆盘半径；不得用 F1 的竖向尺度为 S 重新构造边缘先验。

## 2. 输出与缺失口径

### 2.1 必需输出

对每个任务，区分：

- **点预测**：`point_yz_m` 非空且有限；
- **区域**：`region` 非空、协方差正定、面积有限且大于 0；
- **入框概率**：`goal_probability` 非空；
- **时间区间**：`arrival_time_90_interval_s` 非空且有限。

“至少一项输出有效”不作为成功标准。

### 2.2 主失败率

主失败率定义为：

> 在真实直接过线案例中，**无有效点预测或 无有效区域**的比例。

即任一必需空间输出缺失即记为失败。另列三个子类：

- `no_region`：无有效区域；
- `no_point`：无有效点预测；
- `complete_failure`：无点、无区域、无概率，或数值失败。

主失败率用于选择规则；三个子类用于解释，不互相替代。入框概率缺失不单独改变主失败率，但在 `complete_failure` 和报告表中保留。

### 2.3 覆盖率

- 分母：所有真实直接过线案例（truth event = `goal`），包括框内和框外。
- 缺区域、奇异区域、无点、数值失败和不可用输入均计为漏覆盖。
- 覆盖率为 covered / all true direct；同时报告“区域提供数”和“有效预测比例”。
- 不因方法没有提供区域而把该案例从分母删除。

### 2.4 点误差、面积与有效预测比例

- 点误差：二维欧氏距离 \(\|(\hat Y,\hat Z)-(Y,Z)\|\)，只在 **F0/F1 共同有效点**上配对；同时报告各自的有效点数和提供率。
- 区域面积：只在 **F0/F1 共同有效区域**上配对；同时报告各自区域提供数和提供率。
- 有效预测比例：真实直接过线案例中同时有点和区域的比例；单列，不用它替代覆盖率或失败率。
- 中位数、第 90 分位和面积比均在共同有效案例上计算；不得用各自成功子集的中位数直接比较。

### 2.5 时间指标

- 时间覆盖：分母为所有真实直接过线案例；无时间区间计漏覆盖。
- 时间宽度：在 F0/F1 共同有效时间区间上比较。
- 单列时间区间提供率。
- 即使新开发数据上的时间覆盖达到 90%，也只能称为 **开发集覆盖表现**，不能称为“已校准时间区间”。

## 3. 主选择规则

### 3.1 Bootstrap

- **按机制分层、按源整组配对**：每次在五类机制内部各重采样 20 个源（有放回），合计 100 个源；保留同源四档噪声及三个方法的全部结果，五类机制等权。
- 重采样次数：**10,000**。
- 随机种子：**20261108**。
- 单侧 95% 百分位界：
  - 下界取 10,000 个统计量的第 **5** 百分位；
  - 上界取第 **95** 百分位；
  - 分位数使用 `numpy.quantile(..., method="linear")` 的线性插值定义。
- 若某指标在原样本或任一次重采样中因共同有效案例不足而无法计算：
  - 不删除该重采样；
  - 判为 **证据不足，不采纳 F1**；
  - 报告无效重采样数和原因。
- 这些界是近似抽样推断，不是严格的有限样本保证；失败稀少或机制样本小时须在报告中说明。

### 3.2 五项主条件（F1 相对 F0）

F1 只有同时满足以下五项，且未触发机制保护，才可采纳：

| 指标 | 方向 | 采纳条件 |
|---|---|---|
| 覆盖率差 | F1 − F0 | 源级分层 bootstrap 的 **下界 ≥ −5 个百分点** |
| 区域面积中位数比 | F1 / F0 | 源级分层 bootstrap 的 **上界 ≤ 0.85** |
| 点误差中位数差 | F1 − F0 | 源级分层 bootstrap 的 **上界 ≤ 0.02 m** |
| 点误差第 90 分位差 | F1 − F0 | 源级分层 bootstrap 的 **上界 ≤ 0.05 m** |
| 失败率差 | F1 − F0 | 源级分层 bootstrap 的 **上界 ≤ 2 个百分点** |

面积比在每个重采样内定义为“F1 共同有效区域面积中位数 / F0 共同有效区域面积中位数”，不是逐源面积比的中位数。点误差中位数差与 P90 差也在每个重采样内按共同有效案例计算。

覆盖率差和失败率差的分母均为全部真实直接过线案例；缺失按漏覆盖/失败计。

### 3.3 机制保护

在五类机制内分别计算 F1−F0 的：

- 覆盖率差；
- 主失败率差。

若任一机制出现：

- 覆盖率下降 **> 10 个百分点**；或
- 主失败率增加 **> 5 个百分点**；

则 **否决 F1**，并在报告中指出机制、点估计和源级区间。

未触发否决，只表示“没有明显反例”，不等于证明每个机制都非劣。机制保护使用分层点估计作为额外否决条件，同时报告源级区间；不得用总体平均掩盖单机制明显失效。

### 3.4 决策分类

报告必须区分以下四类，不能把明确恶化统一写成“尚不能区分”：

1. **采纳 F1**：五项主条件全部满足，且未触发机制保护。
2. **证据不足**：点估计方向有利，但至少一项置信界未过门槛；或指标因有效案例不足/无效重采样无法计算。
3. **尚不能确定整体改进**：不同指标收益与代价冲突（例如面积缩小但点误差上界略超、覆盖率下界略低），且未达到明确恶化或机制否决。
4. **不采纳 F1**：明确恶化，或触发机制保护；须指出具体指标、方向、机制和数值。

任一主条件不满足即保留 F0；不临时放宽、不改变分母、不追加样本后重判。

### 3.5 S 的角色

- S 只作结构对照，不参与 F1 的采纳判定。
- F1 不能靠“优于 S”获得通过；S 表现更好也不能替代 F0/F1 的比较。
- S/F0 使用 F0 的 `b_z` 匹配边缘先验；F1/S 的差异不得解释为纯粹的 `b_y` 释放效应。
- 机制分层报告 S/F0，说明 S 在哪些机制受益、哪些机制失效；不做总体单一排名。

## 4. C 的固定设置（先于计算冻结）

C 只复用现有名义 S/F 候选，不生成新样本。以下设置在计算前固定：

- 格网：基准宽 \(2.44/24\approx0.101667\) m；使用 \(0.5\times,1\times,2\times\) 三种格宽，每种格宽使用不平移、仅 y 半格、仅 z 半格、双轴半格，共 12 种格网。
- KDE：加权二维各向同性高斯核；带宽指每轴标准差，主设置为 **0.10 m**；敏感性只报告 0.05 m 和 0.20 m。
- 计算范围：固定 \(Y\in[1.5,4.5]\) m、\(Z\in[0.5,3.0]\) m；网格分辨率 0.01 m；不按入框边界裁剪，门框内外均保留。
- 竞争局部峰：局部极大、密度 ≥ 全局最大值的 **0.8**、与全局峰间距 ≥ **0.10 m**。
- 高密度区：密度不低于全局最大值 **0.8** 的水平集；报告其连通部分及各自质量。该区域 **不是 90% 概率区域**。
- 未发现竞争局部峰，不能单独证明不存在平峰。
- 若某情景自身未通过数值稳定检查，跨假设差异标注：“观测到的跨假设差异，仍混有采样和密度估计误差。”不得挑选最稳定的格网或带宽发布结论。
- C 的发现只用于解释现有结果，不用于修改本文件第 3 节的任何门槛。

## 5. 封存、评价与报告

1. 生成新数据并保存 manifest、源分组、机制标签和噪声种子。
2. 只读取 `observations/development.jsonl` 运行 1200 个任务；预测、候选和诊断先完整保存并计算哈希。
3. 预测封存后，才读取 `truth/development.jsonl`；按源分组评价，四档噪声不视为独立源。
4. 评价顺序：覆盖率 → 失败率 → 点误差 → 面积 → 时间；所有分母、提供数、缺失数和无效重采样数一起报告。
5. 报告必须包含：
   - 五项主条件的点估计、下界/上界和是否通过；
   - 机制分层表与保护触发情况；
   - 决策分类及理由；
   - 实际提议数、墙钟耗时和失败原因；
   - 与 A 审计中假设依赖结论的对照。
6. 不打开 calibration/test；不根据新开发结果回选模型或修改本文件。
